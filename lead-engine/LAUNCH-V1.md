# Mega Lead Engine v1 — launch package

## Objective
Validate whether Mega Limited can acquire qualified private-insurance leads independently of any insurer brand.

## Funnel
Meta ad -> /forsikringstjek/ -> booking request -> Mega-owned lead store -> seller follow-up -> quote -> sale -> annual premium.

## First validation gate
First target: 10 submitted leads. Do not scale based on clicks alone.

Track per lead:
- source / campaign / content
- created timestamp
- booked date/time
- contacted
- qualified
- quote
- sale
- annual premium
- acquisition cost
- seller economics
- expected clawback

## Launch blockers
1. Mega-owned lead destination/storage.
2. Meta Business/ad account access and conversion tracking.
3. Final compliance review before public traffic.
4. User approval of spend before campaign activation.

## Architecture rule
No insurer name in acquisition creative or landing-page positioning. The current insurance partner is introduced later in the regulated sales/advice flow where required.
